fig·03 · ciphertext path · packet routing v3

++ ++

Topology diagram with two switchable views. Transport view: YOU, peer-id 4d2e…f18c, runs a Noise_XX x25519 handshake to the blind relay, which routes opaque ciphertext onward to PEER, peer-id 9c1f…aa07. Relay view (press v): the same path as the relay sees it. Toggle peer offline (o) and packets pause at the relay, drop into the mailbox, and a plus-one tick flashes on the mailbox row; back online they drain. Status readouts are demo values.

fsm-02 · session state machine · edge trace v3

Session state machine. States: invite, handshake, sealed, verified, unverified, wiped, denied. Transitions: invite to handshake via cinder link; handshake to sealed after three noise_xx flights; sealed loops on rekey; sealed to verified on sas match; sealed to unverified on key change, which blocks sends; unverified back to verified on sas match; verified to wiped via chat.wipe; any state to denied via contact.deny. Denied is terminal; there is no un-deny. Each state is a button that highlights and traces its outgoing edges in the readout below.
