05arrowslink endings + drawn runs
fig a · glyph set — semantics per mark
  ⟶  link · href ending            ──▶   drawn · light
  ↦  binding · sas to peer         ══▶   drawn · heavy
  ⇢  pending · queued send         ┄┄▶   drawn · dashed
  ⇒  consequence · therefore       ──►   drawn · small head
  ↪  redirect · relay hop          -->   ascii fallback
  ↗  external · off the wire       ==>   ascii heavy
fig b · in context — link endings
protocol     noise ik spec       ⟶
source       github · cinder     ↗
threats      model · scope       ⇒

arrows terminate a line, never open one. ⟶ is the default link ending; ⇒ marks consequence, ↗ marks anything that leaves the wire.
